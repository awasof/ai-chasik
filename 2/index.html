Коротко

Продолжили разбирать, как меняется работа с ИИ от чата к проекту и агенту. В чате вы прикладываете нужные файлы сами, в проекте часть контекста уже собрана, а агент может взять на себя несколько шагов. На примере анализа интервью обсудили, какие промежуточные результаты сохранять и что проверять вручную.

На демонстрации агент собрал корзину продуктов через MCP. Затем сравнили два черновика гайда интервью: по обычному запросу и с навыком. Навык помог задать порядок работы, но для точного гайда всё равно нужен бриф.

Лайфхаки

  • Сохраняйте выводы по каждому интервью 23:35

    При разборе серии интервью сохраняйте промежуточные выводы отдельными файлами. Затем соберите по ним общую сводку.

  • Прикладывайте бриф к задаче 44:43

    Навык задаёт способ работы. Бриф даёт исходные данные, без которых ИИ придётся делать допущения.

  • Проверьте источники для задачи по расписанию 49:13
