# AI-часик — сайт-библиотека

Записи и короткие конспекты AI-часиков для исследователей. Модератор — Игорь Волошин.

- Сайт: https://awasof.github.io/ai-chasik/
- Репозиторий: `awasof/ai-chasik` — **источник правды**. Сайт лежит в корне (GitHub Pages: ветка `main`, корень), исходники — в `_src/`.
- Копия исходников у Игоря: `~/Desktop/VTB/Education/AI часик/` (зеркало, обновляется после каждой публикации).
- Каждый новый часик обрабатывается скиллом **ai-chasik**.

Отдельный сайт, не связанный с курсом: никаких ссылок с сайта курса сюда, никаких «недель». Закрыт от поисковиков: `noindex` в каждой странице, `robots.txt`, ссылки наружу без referrer.

## Что в `_src/`

| Что | Зачем |
|---|---|
| `content/NN.json` | Данные часика: дата, ссылка на запись, резюме, темы, лайфхаки, вопросы из зала, что попробовать, термины. У каждого пункта `t` — секунда записи в Dion |
| `assets/style.css`, `assets/app.js` | Стиль и скрипт: поиск, «Скопировать», подсветка темы на циферблате |
| `build.py` | Сборка: `python3 build.py` → `site/` (пишет число слов конспекта) |
| `publish.py` | Сборка + раскладка сайта в корень репозитория. Запуск из корня клона: `python3 _src/publish.py` |
| `slides/<slug>/` | Слайды к часикам. Колода: `data.json` (слайды, промпты, домашка, материалы, словарь), `host.json` (заметки ведущего: шпаргалка показа, что подготовить), `files/` (файлы для скачивания), `shots/` (скриншоты, имя как в заглушке на слайде). Колоды ещё нет — только `meta.json` с `placeholder`. У колоды «Штаб, часть 1» `data.json` и `host.json` собирает `build_data.py`: правки — в нём, ссылки на слайды — ключами `@@key@@`, номера считаются сами |
| `slides.py`, `lecture.py`, `lecture/` | Сборка слайдов на движке сайта лекций курса: `lecture/app.js` — его обобщённая копия, `brand.css` и `fonts/` — фирменный стиль курса |

## Как устроен сайт

- **Главная** — поиск по всем часикам и список встреч, новые сверху, у каждой мини-циферблат.
- **Страница часика** — коротко, о чём говорили (с циферблатом по минутам), лайфхаки, вопросы из зала, что попробовать, термины. Читается за 3 минуты.
- **Указатель** — все термины по алфавиту, лайфхаки и вопросы со всех часиков.
- **Слайды** — у каждого слайда своя страница: сверху слайд 16:9, ниже разделы A, B, C — промпты с кнопкой «Скопировать», файлы, «Если не получилось», «Как это в Codex». ← → листают, ↓ ↑ — разделы, F — только слайд, N — заметки ведущего, P — пульт во втором окне, M — содержание. Заметки видит любой, кто нажмёт N, поэтому в них только то, что можно показать. Слайд не помещается в 16:9 — текст уносится под слайд, а не ужимается шрифт.
- Жёлтое время открывает запись в Dion на нужной минуте: `?start_from=<секунды>` (сборка ставит на 3 секунды раньше `t`).

## Правила

- Без названия банка и отдела, без имён коллег — «вопрос из зала», «из зала».
- Нумерация — просто «часик 1, 2, 3», без недель курса.
- Конспект ≤ ~650 слов (3 минуты чтения).
- В Dion у записи доступ «Все авторизованные пользователи по ссылке».
