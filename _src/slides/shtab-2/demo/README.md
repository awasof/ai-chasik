# Демо штаба для второго часика

В `projects/` пять готовых вымышленных карточек. В `README.md` каждой карточки есть полный список стадий с отметками о завершении и ролями. Расширение показывает первую открытую стадию, кто её ведёт, кто подтверждает результат и за кем сейчас шаг. На доске также видны прогресс, отдельные чек-листы и напоминания.

## Подключение в Chrome

1. Распакуйте ZIP. Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите «Загрузить распакованное расширение». Укажите папку `demo-shtaba/chrome-extension`, в которой лежит `manifest.json`.
2. Нажмите значок расширений (пазл) и закрепите «Штаб исследователя». По клику на закреплённый значок откроется вкладка дашборда.
3. На дашборде нажмите «Подключить папку штаба» и выберите `demo-shtaba`. Для своего штаба выбирайте папку с `projects/`. Chrome попросит разрешить чтение. При следующем открытии может понадобиться кнопка «Разрешить чтение».

[Установка и закрепление распакованного расширения в документации Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

Пока вкладка открыта, дашборд перечитывает карточки каждые пять секунд и при возврате во вкладку. Редактируйте Markdown на диске или через агента. Напоминания отображаются на доске, которую для этого нужно открыть.

| Проект | Колонка | Что показать |
| --- | --- | --- |
| Первый заказ с доставкой | To do | Бриф поступил, исследователь ещё не начал работу. |
| Возврат заказа в приложении | Ongoing | Анализ готов. Агент уточняет, подтвердил ли его лид на встрече или вернул с правками. |
| Самовывоз из пункта выдачи | Ongoing | Презентация и отправка подтверждены. Агент уточняет, загружен ли проект в библиотеку. |
| Поиск по каталогу | Done — контроль эффекта | Результаты переданы, назначена проверка эффекта. |
| Уведомления о доставке | Done — контроль эффекта | Эффект зафиксирован. |

Для прогона откройте дашборд и карточку «Возврат заказа». В разделе «Стадии проекта» отмечено «Анализ готов», а проверка лида ещё открыта. Когда лид подтвердит выводы, отметьте стадию галочкой и проверьте, что дашборд показывает 7 из 9 и следующий этап. Затем в проекте «Самовывоз» подтвердите загрузку в библиотеку. В разделе «Передача результатов» поставьте отметку, измените `status` на `done` и добавьте `проверка_эффекта: 2026-12-01`. Карточка остаётся в `projects/samovyvoz/README.md`, а проект переходит в другую колонку.

Без расширения можно открыть [снимок дашборда](dashboard.html). Для снимка используется ручная пересборка командой `python3 build_dashboard.py`. В шапке карточки каждое поле записывается одной строкой `ключ: значение`, даты — в формате `ГГГГ-ММ-ДД`.
