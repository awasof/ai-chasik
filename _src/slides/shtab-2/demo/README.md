# Демо штаба для второго часика

В `projects/` пять готовых вымышленных карточек. Начните с `dashboard.html`. Этот файл открывается без интернета и показывает три уровня дашборда на снимке учебных карточек. Изменения действуют до перезагрузки страницы.

1. В **Обзоре** сравните To do, Ongoing и Done — контроль эффекта. Проекты остаются в Done до архивирования.
2. Нажмите **Ongoing**. Здесь видны стадии и по каким проектам на них сейчас работаем. Выберите исследователя или посмотрите всех.
3. Откройте «Самовывоз из пункта выдачи». Отметьте загрузку в библиотеку, запишите подтверждение и дату контроля эффекта. Проверьте предлагаемый переход и нажмите «Сохранить в карточке». В HTML-прототипе это обновит учебный пример. В расширении обновится реальный README.md выбранной учебной папки.

Для сборки HTML заново выполните в этой папке `python3 build_dashboard.py`. Он прочитает текущие учебные карточки и обновит снимок. Затем переходите к [установке расширения](chrome-setup.md), чтобы проверять реальные изменения Markdown-файлов.

Для показа перехода по артефакту откройте `inbox/itogi-brifinga-dostavka.md`. Попросите агента сверить его с правилами «Первого заказа с доставкой». Сначала покажите ожидаемые изменения без записи, чтобы в обзоре остался пример To do.
