# Демо штаба для второго часика

В `projects/` пять вымышленных проектов. Каждая папка содержит карточку `README.md`. Дашборд читает поля из шапок карточек и открывается локально, без интернета.

| Проект | Колонка | Что показать |
| --- | --- | --- |
| Первый заказ с доставкой | To do | Бриф поступил, исследователь ещё не начал работу. |
| Возврат заказа в приложении | Ongoing | Анализ готов. Агент уточняет, подтвердил ли его лид на встрече или вернул с правками. |
| Самовывоз из пункта выдачи | Ongoing | Презентация и отправка подтверждены. Агент уточняет, загружен ли проект в библиотеку. |
| Поиск по каталогу | Done — контроль эффекта | Результаты переданы, назначена проверка эффекта. |
| Уведомления о доставке | Done — контроль эффекта | Эффект зафиксирован. |

Для прогона откройте [дашборд](dashboard.html). По промпту обновления статуса попросите агента проверить «Самовывоз». Когда он спросит про библиотеку, скажите, что загрузили проект 17 ноября, а контроль эффекта назначили на 1 декабря. После согласования агент отмечает загрузку, меняет `status` на `done` и добавляет `проверка_эффекта: 2026-12-01`. Карточка остаётся в `projects/samovyvoz/README.md`.

Чтобы пересобрать демо, запустите в этой папке `python3 build_dashboard.py` и обновите страницу. В шапке демо-карточки каждое поле записывается одной строкой `ключ: значение`, даты — в формате `ГГГГ-ММ-ДД`.
