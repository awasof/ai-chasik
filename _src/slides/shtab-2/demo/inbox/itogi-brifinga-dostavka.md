# Итоги брифинга о первом заказе с доставкой

Учебный пример для проекта «Первый заказ с доставкой» (`projects/dostavka/`).

На встрече договорились выяснить, на каких шагах люди откладывают свой первый заказ. Исследователь подготовит план исследования и обсудит его с лидом и заказчиком.

Итоги отправлены заказчику после встречи. Это отметка о передаче итогов, которую агент может сверить с правилом стадии «Брифинг проведён».
