# Учебный штаб

- Работай с карточками в `projects/`. Правила стадий и статусов в `team-rules.md`.
- Уточняй недостающие факты по одному. Устное подтверждение записывай со слов исследователя. Дождись «ок» перед сохранением.
- Папка проекта остаётся на своём пути. Статус хранится в поле `status` карточки `README.md`.
- После сохранения обнови список проектов в `projects/index.md` и выполни `python3 build_dashboard.py` в этой папке.
