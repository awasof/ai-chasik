# Учебный штаб

- Работай с карточками в `projects/`. Правила стадий и статусов в `team-rules.md`.
- Уточняй недостающие факты по одному. Устное подтверждение записывай со слов исследователя. Дождись «ок» перед сохранением.
- Папка проекта остаётся на своём пути. Статус хранится в поле `status` карточки `README.md`.
- В разделе «Стадии проекта» храни весь перечень из `team-rules.md`. Отмечай завершённое как `- [x]` и добавляй подтверждение рядом. В разделе «Передача результатов» веди отправку заказчику и загрузку в библиотеку. Чек-лист мелких действий веди отдельно от стадий.
- Для каждой стадии добавляй ` · Ответственный: <имя или роль>` и, если нужно, ` · Подтверждает: <имя или роль>`. Поле `за_кем_шаг` обновляй отдельно по текущей договорённости.
- Для напоминания используй `напомнить` (дата `ГГГГ-ММ-ДД`) и `напоминание` (действие). Для даты контроля эффекта используй `проверка_эффекта`.
- После сохранения обнови список проектов в `projects/index.md`, если он есть. Дашборд расширения прочитает карточки при следующем обновлении.
