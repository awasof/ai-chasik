# Стадии проекта в штабе исследователя

Рабочая версия для второй встречи про штаб, «Процесс: пайплайн и дашборд». По ней участники настраивают `team-rules.md` и проверяют следующий шаг на своих проектах.

| Стадия | Что подтверждает завершение |
| --- | --- |
| 1. Бриф получен | Заполненный бриф или письмо заказчика. |
| 2. Брифинг проведён | Итоги установочной встречи отправлены заказчику. |
| 3. Дизайн утверждён | План исследования и подтверждение согласования с лидом и заказчиком. |
| 4. Инструмент утверждён | Гайд, выборка и скринер либо анкета и квоты, с подтверждением заказчика. |
| 5. Поле завершено | Транскрипты или выгрузка полевых данных. |
| 6. Анализ готов | Выводы с цитатами или расчётами. |
| 7. Анализ проверен лидом | Подтверждение лида с датой проверки или ссылкой на сообщение. Если лид вернул анализ с правками, следующий шаг — внести их и повторно показать анализ. |
| 8. Презентация проведена | Отчёт, рекомендации и дата показа заказчику. |
| 9. Эффект зафиксирован | Обратная связь заказчика и сведения о применении результатов. |

В `README.md` каждого проекта есть раздел «Стадии проекта». Запишите в нём весь список стадий. Ставьте `- [x]`, когда есть подтверждение завершения, и оставляйте `- [ ]`, пока стадия открыта. Рядом можно указать дату, ссылку на файл или запись устного подтверждения. Дашборд показывает прогресс и первую открытую стадию. Для отслеживания достаточно карточки проекта. Материалы можно хранить там, где их удобно найти.

После презентации в карточке проекта отмечаются два действия. Обе отметки нужны для закрытия передачи результатов.

- [ ] **Результаты отправлены заказчику.** Дата и ссылка на письмо или сообщение с результатами.
- [ ] **Проект загружен в библиотеку.** Дата и ссылка на карточку или папку проекта в библиотеке.

Статус хранится в поле `status` карточки `projects/<имя-проекта>/README.md`. На дашборде три колонки: **To do**, **Ongoing**, **Done — контроль эффекта**. Путь к папке проекта постоянный.

Если анализ готов и подтверждения лида ещё нет, проект остаётся в **Ongoing** со следующим шагом «Показать анализ лиду». После презентации дашборд показывает каждое незакрытое действие по передаче результатов. Когда обе отметки стоят, проект переходит в **Done — контроль эффекта**. Там видна дата следующей проверки или итог «Эффект зафиксирован».
