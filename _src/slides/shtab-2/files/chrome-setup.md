# Как добавить дашборд в Chrome

1. Распакуйте учебный архив в отдельную папку. Откройте `dashboard.html` и проверьте три представления. HTML показывает снимок карточек. Галочки в нём можно попробовать без изменения файлов.
2. В Chrome откройте `chrome://extensions`. Включите «Режим разработчика» и выберите «Загрузить распакованное расширение». Укажите папку `chrome-extension`, в которой лежит `manifest.json`.
3. Откройте меню расширений (значок пазла) и закрепите «Штаб исследователя». По клику на значок откроется доска.
4. Нажмите «Подключить папку штаба». Выберите корень с `projects/`, `team-rules.md` и `dashboard-rules.json`. Chrome разрешит читать выбранную папку. После перезапуска он может попросить разрешение снова.
5. Откройте Ongoing, затем «Самовывоз из пункта выдачи». В разделе передачи результатов отметьте загрузку в библиотеку, введите подтверждение и дату проверки эффекта. Перед сохранением проверьте предлагаемый переход в Done.
6. При первом сохранении разрешите Chrome записать изменения в карточку. Убедитесь, что «Самовывоз» оказался в Done и галочка появилась в его `README.md`.

В своём штабе сначала сверьте `dashboard-rules.json` с `team-rules.md`. Ключ `startStages` задаёт завершённые стадии для перехода из To do в Ongoing. Ключи `doneStages` и `doneChecks` задают обязательные стадии и пункты передачи для Done. Названия должны совпадать с карточками. Пример загружается в **отдельную учебную папку**, где можно спокойно проверить результат.

[Установка распакованного расширения в документации Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)
